# Digital Library Management System

A complete responsive frontend library management project built with HTML5, CSS3, vanilla JavaScript ES6, and browser Local Storage.

## Run the project

1. Open the `Digital-Library-Management-System` folder in VS Code.
2. Install and start the Live Server extension.
3. Open `index.html` through Live Server.
4. Choose **Get Started**, then sign in.

## Security note

This is a frontend-only college demonstration. Passwords are stored in browser Local Storage in plain text for demonstration purposes and must not be used for real authentication or production systems.

## Main features

- Welcome, login, and registration pages
- Protected dashboard and internal navigation
- Book and member CRUD operations
- Search and category filters
- Book issue and return workflows
- Live dashboard and report statistics
- Print and CSV export
- Responsive desktop, tablet, and mobile layouts
