Digital Library

Built for academic learning and service

About the System

The Digital Library Management System organizes collections, members, issues, returns, and reports in a responsive browser-based application.

Project Purpose

It demonstrates an MCA-level full-stack frontend concept while keeping data consistent in browser Local Storage.

Facilities

  • Dynamic book and member records
  • Issue and return tracking
  • Live dashboard and reports
  • CSV export and print support

Technologies

HTML5, CSS3, JavaScript ES6, Browser Local Storage, and VS Code Live Server.
